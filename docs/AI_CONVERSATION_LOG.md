   > ייצוא כזה כבר נוצר במהלך העבודה: `~/Downloads/session-export-1793273780092.zip` (33MB). ממנו נוצר התמלול המצורף.

   ```bash

   python3 scripts/transcript_to_md.py ~/Desktop/deni-export/transcript.jsonl docs/ai-transcript/TRANSCRIPT.md
   ```
3. **PDF:** לפתוח את קובץ ה־Markdown ב־VS Code (Preview) או בדפדפן, ולהדפיס ל־PDF (‎Cmd+P ← "שמור כ־PDF").
