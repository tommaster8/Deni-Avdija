# Game Night: דני אבדיה – המסע ל־NBA

מצגת אינטראקטיבית בסגנון שידור ספורט, שנבנתה ב־HTML, CSS ו־JavaScript בלי ספריות חיצוניות.
התכנון המלא נמצא ב־[docs/PRD.md](docs/PRD.md), ותיעוד התהליך ב־[docs/DECISION_LOG.md](docs/DECISION_LOG.md).

## הרצה מקומית (Mac)
בטרמינל, מתוך תיקיית הפרויקט:

```bash
python3 -m http.server 5173
```

ואז לפתוח את http://127.0.0.1:5173 בדפדפן. אפשר גם לפתוח את `index.html` ישירות, בלחיצה כפולה.

## ניווט
| פעולה | מקלדת | עכבר / מגע |
|---|---|---|
| שקופית הבאה | ← · רווח · PageDown | כפתור ← · החלקה ימינה |
| שקופית קודמת | → · PageUp | כפתור → · החלקה שמאלה |
| ראשונה / אחרונה | Home / End | נקודות הניווט |
| Replay של השקופית | R | – |
| מצב "ישראל ערה" | N · Esc לסגירה | לחיצה על השעון |

קישור ישיר לשקופית: `index.html#7`.

### הרחבה
- **שקופית חדשה:** מוסיפים `<section class="slide" data-quarter="Q3" data-title="...">` ב־`index.html`. הניווט, הנקודות והמונה מתעדכנים לבד.
- **אנימציית כניסה:** מוסיפים `data-anim` לכל רכיב.
- **רכיב שמגיב לכניסה לשקופית:** `GN.onSlideEnter((slide) => { ... })`.
- **רגע של השעון הישראלי:** מוסיפים רשומה ל־`CLOCK_MOMENTS` ב־`data.js`, ואת `data-moment="..."` לשקופית.
